Native libraries built from source into XCFrameworks for Xcode and SwiftPM — and for Android, Windows and Linux.

- **[otok](https://github.com/otok-dev/otok)**: the program. Install it with `brew install otok-dev/tap/otok`
  or from [Scoop](https://github.com/otok-dev/scoop-bucket).
- **[Documentation](https://otok-dev.github.io/)**: getting started, coming from CocoaPods, writing recipes.
- **[Catalog](https://otok-dev.github.io/index/)** of the libraries otok builds, from the
  [index](https://github.com/otok-dev/index) where recipes are published.
- **[Recipes](https://github.com/otok-dev/recipes)** for libraries that have no other home.
